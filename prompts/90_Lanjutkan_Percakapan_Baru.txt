KONDISI SAAT INI:
- Website adalah SISTEM INFORMASI MANAJEMEN & PEMANTAUAN GERAI KOPERASI (bukan kasir POS).
- Modul inti aktif:
  * Dashboard Manajer (/dashboard) — KPI metrik, tren omset 7 hari, tugas mendesak, kepatuhan pelaporan
  * Manajemen Tugas & Agenda (/pekerjaan) — daftar tugas + kalender agenda bulanan
  * Pemantauan Gerai (/monitoring) — input rekap harian manual + riwayat
  * Daftar & Edit Gerai (/unit-usaha) — profil gerai, PIC, target omset
  * Barang & Stok (/stok) — pantau angka stok fisik sederhana
  * Data Anggota (/anggota) — daftar dan jumlah anggota koperasi
  * Kas & Buku Besar (/keuangan) — buku besar kas, mutasi setoran, simpanan anggota
  * Neraca & SHU (/laporan) — neraca seimbang, laba rugi, alokasi SHU sesuai AD/ART
- Database Supabase: 7 tabel inti (migrasi 20260923000007_clean_simple_schema.sql)
- API aktif: /api/dashboard/executive, /api/tasks, /api/units, /api/monitoring/records, /api/stock-simple, /api/members, /api/finance/summary
- Pengujian: 95 unit test lulus 100%, TypeScript typecheck 0 galat, build Next.js sukses.
- Desain: Pastel lembut, gradient halus, aksen rose #A64768, Plus Jakarta Sans, sidebar kiri, target tablet.
- Fondasi visual v2.2: Input/Select/DateInput/Textarea seragam, dialog responsif, kalender ramah tablet/ponsel, serta tema Terang/Gelap/Ikuti Perangkat.
